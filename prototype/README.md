# 蜂汇智理 · 产品原型（AI 3 交付）

> 本目录由 **AI 3 产品原型与演示工程师** 维护。其他 AI 只读，需要修改请在 PR 评论或交接记录中提出。

## 这是什么

一套**零依赖、可离线、可重复录屏**的三端产品原型，用于演示「骑手上报 → AI 处理与建议 → 治理人员人工决定 → 处置反馈 → 服务型激励 → S0–S3 仿真比较」的完整治理闭环。

- 打开方式：直接双击 `app/index.html`（Chrome / Edge 均可），**无需服务器、无需构建、无外部网络请求**；需 Chrome 62+ / Edge 79+ 等现代浏览器。
- 演示时长：主线闭环 2 分 30 秒（见 `demo-script.md`）。
- 数据性质：**产品数据全部为虚构或脱敏的演示数据**；**仿真数值为 AI 2 第一轮合成仿真结果**（每情景 20 次重复、240 名合成从业者、56 个模拟日、配对共同随机数），在当前项目假设下得出，不是现实统计或政策效果证明。
- 仍缺材料：关键参数敏感性分析、第一轮最终汇总、玉兰万象平台复跑 → 界面以 `SIM_RESULT_NEEDED_*` 显式标注，**不以估计值代替**。
- 系统边界：**不接入**任何政府、物业、外卖或网约车平台生产系统；AI 输出**仅为建议**，必须由治理人员人工确认；严重事故、火灾或治安事件提示转接 **110 / 119 / 120 / 122**，平台不替代法定应急渠道。
- 版本：v0.2（第二轮）。相对 v0.1 的变化：仿真数值替换为真实结果并加 95% 区间、参与差距改为两类群体口径、时间成本改称「平均上报耗时」、新增数据用途与单独同意流程、AI 生成内容标识、申诉入口、紧急事件专用留存页、上报人可修改描述、演示模式不再隐藏声明条。

## 运行与自检

```powershell
# 1 打开原型（也可以直接双击 index.html）
start prototype/app/index.html

# 2 自检：核验脱敏、分类、合并、风险分级、建议分派、占位标记与安全边界
node prototype/app/selftest.js

# 3 重新生成截图（需要本机安装 Edge 或 Chrome）
node prototype/app/shot.js
```

## 一句话边界（答辩口径）

1. 原型用规则表演示可解释的 AI 流程，不代表真实模型能力，也未评估准确率。
2. 仿真数值为第一轮合成仿真结果，**不是现实统计**；每处引用都要带「第一轮 / 项目假设 / 20 次重复 / 95% 区间」。
3. AI 只给建议，人工必须确认；系统不存在自动分派路径。
4. 紧急事件不进入普通流程，提交后进入专用留存页，只提示法定应急渠道。
5. 未接入任何生产系统，地图为示意底图，网格编号虚构。
6. **不使用「显著」**（未做显著性检验）；参与差距不得说成缩小（S2→S3 区间跨越 0）。
7. 敏感性分析、最终汇总、平台复跑尚未产出，界面以 `SIM_RESULT_NEEDED_*` 标注，不以估计值代替。
