# 蜂汇智理 · 产品原型（AI 3 交付）

> 本目录由 **AI 3 产品原型与演示工程师** 维护。其他 AI 只读，需要修改请在 PR 评论或交接记录中提出。

## 这是什么

一套**零依赖、可离线、可重复录屏**的三端产品原型，用于演示「骑手上报 → AI 处理与建议 → 治理人员人工决定 → 处置反馈 → 服务型激励 → S0–S3 仿真比较」的完整治理闭环。

- 打开方式：直接双击 `app/index.html`（Chrome / Edge 均可），**无需服务器、无需构建、无外部网络请求**。
- 演示时长：主线闭环 2 分 30 秒（见 `demo-script.md`）。
- 数据性质：**全部为虚构或脱敏的演示数据**；仿真数值带 `PLACEHOLDER_SIM_RESULT` 标记，属**占位数据，不是实验结果**。
- 系统边界：**不接入**任何政府、物业、外卖或网约车平台生产系统；AI 输出**仅为建议**，必须由治理人员人工确认；严重事故、火灾或治安事件提示转接 **110 / 119 / 120 / 122**，平台不替代法定应急渠道。

## 运行与自检

```powershell
# 1 打开原型（也可以直接双击 index.html）
start prototype/app/index.html

# 2 自检：核验脱敏、分类、合并、风险分级、建议分派、占位标记与安全边界
node prototype/app/selftest.js

# 3 重新生成截图（需要本机安装 Edge 或 Chrome）
node prototype/app/shot.js
```

自检覆盖 87 项断言，包含：脱敏规则、结构化、分类与置信度、重复检测、风险分级、
建议分派、人工决定链路、指标口径、占位标记、紧急分流与「无自动分派」检查。

## 一句话边界（答辩口径）

1. 原型用规则表演示可解释的 AI 流程，不代表真实模型能力，也未评估准确率。
2. 仿真数值是占位数据，不是实验结果，第二轮由 AI 2 结果替换。
3. AI 只给建议，人工必须确认；系统不存在自动分派路径。
4. 紧急事件不进入普通流程，只提示转接法定应急渠道。
5. 未接入任何生产系统，地图为示意底图，网格编号虚构。
