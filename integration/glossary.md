# 蜂汇智理统一术语表

| 统一术语 | 统一定义 | 禁用或慎用表述 |
| --- | --- | --- |
| 蜂汇智理 | 新就业群体参与城市治理的 AI 协同与仿真平台 | 不简称为已上线政务平台 |
| 新就业群体 | 本项目主要指外卖骑手和网约车司机 | 不以 30 人样本推断全国群体比例 |
| 城市问题上报 | 对设施、环境、通行等非紧急问题提供线索 | 不写成执法举报或应急报警替代渠道 |
| AI 建议 | AI 对脱敏、结构化、去重、分类、风险与分派给出的辅助结果 | 不写“AI 决策”“自动执法” |
| 人工确认 | 治理人员对 AI 建议进行接受、修改、退回或转交 | 不写成形式审核 |
| 透明反馈 | 向上报者展示责任主体、处理进度和结果摘要 | 不承诺公开敏感处置细节 |
| 服务型激励 | 积分、驿站权益、托管优先权等非强迫性服务权益 | 不写现金奖励、排名惩罚或平台派单倾斜 |
| 有效上报率 | 经人工复核后可形成有效治理工单的上报占比，最终公式以 AI 2 模型为准 | 不与上报总量混同 |
| 重复或无效上报率 | 被合并为重复事件或人工判定无法形成工单的占比 | 不把被合并事件等同恶意上报 |
| 工单分派准确率 | 建议责任主体与人工确认责任主体一致的比例 | 未经人工确认不得称“准确” |
| 平均处置时间 | 从工单成立到进入已完成状态的平均时间 | 不把 AI 处理耗时当作完整处置时间 |
| 参与者时间成本 | 发现问题后用于上报、补充和查看反馈的时间 | 不等同工作收入损失，除非另有模型 |
| 参与差距 | 不同新就业群体在参与概率或有效上报率上的差异 | 不表述为群体能力差异 |
| 项目假设 | 缺少可靠现实数据时，为建模而设定且需敏感性分析的参数 | 不写成调研事实 |
| 合成数据 | 为原型演示或社会仿真生成的虚构数据 | 不写成真实调查、真实工单或现实运行结果 |
| 模型显示 | 对当前模型、参数和运行结果的有限解释 | 不写“实践证明”“现实中必然” |
| 严重事件 | 涉及事故、火灾、治安、急救等需法定应急渠道处置的事件 | 不进入普通 AI 工单闭环 |

## 占位符规范

- `CITATION_NEEDED_<主题>`：待 AI 1 提供事实或官方来源。
- `SIM_RESULT_NEEDED_<指标>`：待 AI 2 提供可复现结果。
- `SCREENSHOT_NEEDED_<页面>`：待 AI 3 提供最终界面证据。
- 占位符在最终提交前必须全部替换、弱化或删除。
