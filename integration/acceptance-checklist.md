# 蜂汇智理验收清单

## A 官方要求

- [ ] 赛道二名称、题目和参赛资格已核对。
- [ ] 报告、视频、代码和附件要求已核对。
- [ ] 格式、页数、时长、大小、命名和截止时间已核对。
- [ ] 每项官方评分标准均映射到报告、视频和证据。

## B 事实与来源

- [ ] 外部事实均有来源链接和访问日期。
- [ ] 政策名称、发布主体、日期和原文含义准确。
- [ ] 30 人访谈仅作为定性材料，不宣称总体比例。
- [ ] 调研引语和案例已脱敏且获得可用授权。
- [ ] 所有 `CITATION_NEEDED` 已替换、弱化或删除。

## C 仿真与数字

- [ ] S0–S3 只改变约定机制。
- [ ] 六项固定指标均有明确定义和单位。
- [ ] 每个参数标注“来自材料”或“项目假设”。
- [ ] 每场景至少完成计划次数的重复运行并报告波动。
- [ ] 报告、图表、视频数字与原始输出一致。
- [ ] 模型版本、参数、随机种子、日志和代码可追溯。
- [ ] 已完成关键参数敏感性分析。
- [ ] 所有 `SIM_RESULT_NEEDED` 已替换或删除。

## D 产品与演示

- [ ] 骑手端、治理端、仿真端可稳定打开。
- [ ] 语音、文字、图片和位置上报均被正确描述。
- [ ] 脱敏、结构化、去重、分类、风险和建议分派可演示。
- [ ] AI 建议与人工决定在界面上明确区分。
- [ ] 严重事件提示 110、119、120 或 122。
- [ ] 测试数据均为虚构或脱敏数据。
- [ ] 不宣称生产系统接入或自动执法。
- [ ] 三分钟内可完成核心治理闭环。
- [ ] 所有 `SCREENSHOT_NEEDED` 已替换或删除。

## E 报告与视频一致性

- [ ] 项目名称、一句话定位、研究问题和场景名称一致。
- [ ] 报告图表可追溯到实验结果或产品截图。
- [ ] 视频旁白只描述已实现和已核验内容。
- [ ] 所有截图为最终版本且无个人信息。
- [ ] 视频字幕、旁白、画面数字相互一致。
- [ ] 关键局限和安全边界在报告与视频中均有表达。

## F 安全与隐私

- [ ] 原始语音、图片与精确位置按最小权限隔离。
- [ ] 脱敏前后数据用途、留存和删除规则可解释。
- [ ] 日志不记录密钥、验证码或完整个人信息。
- [ ] 不上传 `.env`、密钥、未授权录音和真实敏感材料。
- [ ] 人工修改、退回、转交和结案均有审计记录。

## G 提交包

- [ ] README 能指导评委在最短路径理解项目。
- [ ] 报告源文件与最终 PDF 版本一致。
- [ ] 视频可播放，链接权限与校验信息有效。
- [ ] 代码和复现说明在干净环境完成一次检查。
- [ ] 压缩包目录清晰，无缓存、临时文件和大型无关文件。
- [ ] 最终提交前由 AI 1、AI 2、AI 3 完成三项专业审计。
