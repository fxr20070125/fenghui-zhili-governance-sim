# 现有调研材料建模摘录

以下是 AI 2 从团队现有调研报告提取的方向性依据，仅用于定义角色、变量和机制。

| 报告位置 | 定性发现 | 模型用途 |
|---|---|---|
| 调研方法与样本概况 | 17 名骑手、5 名网约车司机、2 名站长、6 名政府及社区人员，共 30 人 | 建立角色类型；不外推比例 |
| 收入与工作强度 | 骑手工作时长可达 8—12 小时，司机收入成本压力突出 | 时间压力、工作类型异质性 |
| 平台算法 | 卡餐会引发连锁超时，客观绕路未充分计时 | 上报时间成本和问题发现背景 |
| 末端配送 | 门禁、无人值守、信号、修路和门牌错误造成进入困难 | `community_access` 问题类型 |
| 站点支持 | 多位骑手遇到问题优先找站长 | 站长代理和信任变量 |
| 家庭照护 | 托管名额紧张、知晓度低，老人赡养与子女照护需求分层 | `care_pressure`、`service_need` |
| 新渭骑士 | 骑手参与路面修整、路灯安装等治理，长期关系带来归属感 | 公民动机、信任动态、反馈机制 |
| 激励链条 | 积分兑换吸引力有限，托育等实质性福利不足 | S3 使用差异化服务权益 |
| 平台建议 | 提出“上报—派单—处置—反馈—积分”闭环 | S0—S3 行为链 |
| 报告局限 | 单一区域、定性访谈、无问卷量化、高流动性 | 所有数值标记为假设并做敏感性分析 |

报告中的时间、收入和人数只用于说明存在的现象，不直接转化为普遍概率。第一轮对所有微观行为效应采用显式项目假设。
