# 玉兰万象 S3 平台运行归档

## 归档范围

- 场景：蜂汇智理快速版，`scenario_id=S3`。
- 平台模型：`OneSim(qwen)`。
- 运行 ID：`20260915_232232`。
- 运行规模：5 次独立运行，每次依次执行 11 个动作，共 55 次决策；平台报告记录为 55/55 成功。
- Agent：4 类，平台本次画像池共 10 个实例；每次运行实际选择 1 名从业者、1 个治理工作流、1 个指标记录器和 1 个场景控制器。
- 数据性质：全部为合成数据。

`generated-code/` 保存从玉兰万象代码页面逐文件复制的源码。`SimEnv.py` 根据用户提供的页面文本整理了排版与文件头，其余 Python 文件仅去除粘贴文本的文件名首行和统一的两空格外层缩进。`platform-report.txt` 是平台生成的完整报告文本。

## 结论边界

这次运行证明了快速版的 4 类 Agent、11 动作行为链能够在玉兰万象完成模板代码生成、语法校验和端到端执行。但它没有形成可用的 S3 量化结果：`case_state` 没有被治理处理器更新，跨轮 `metrics_container` 发生断链，平台报告明确显示未采集到自定义指标或量化时序数据。

因此：

- 本归档可作为玉兰万象迁移、平台运行和工程诊断证据；
- 不得把报告中的零值、个案叙事或“1/3”等临时口径当作 S3 正式实验指标；
- S0—S3 的正式量化比较以仓库 `simulation/results/` 下的本地可复现实验为准。

详细原因见同目录的 `code-audit.md`。
