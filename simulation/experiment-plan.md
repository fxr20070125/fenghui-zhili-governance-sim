# 第一轮实验计划

## 1 假设

- H1：S1 相比 S0 降低上报耗时与重复/无效率，并提高分派准确率和问题覆盖率。
- H2：S2 相比 S1 通过透明反馈改善后期持续参与和处置表现。
- H3：S3 相比 S2 提高后期参与和问题覆盖；是否缩小群体参与差距是待检验结果，不预设必然成立。
- H4：紧急事件在所有情景中均不进入普通治理工单，安全边界不因效率目标而改变。

## 2 试验矩阵

| 项目 | 设置 |
|---|---|
| 情景 | S0、S1、S2、S3 |
| 重复 | 每个情景 20 次，共 80 次运行 |
| 每次人口 | 240 名合成从业者 |
| 时长 | 56 个模拟日 |
| 基础种子 | 20260914 |
| 比较方法 | 同一 run 下的情景配对比较 |
| 置信区间 | 跨 20 次运行的均值 ± 1.96×标准误 |

## 3 指标口径

| 指标 | 公式 | 趋势偏好 |
|---|---|---|
| 有效上报率 | 有效独立上报及成功合并佐证数 ÷ 普通原始上报数 | 高 |
| 重复或无效率 | 无效上报及未合并重复数 ÷ 普通原始上报数 | 低 |
| 分派准确率 | 正确分派工单数 ÷ 工单数 | 高 |
| 平均处置时间 | 已解决工单处置小时均值 | 低 |
| 平均上报耗时 | 所有实际上报（含应急转接）的分钟均值 | 低 |
| 群体参与差距 | 骑手参与率与司机参与率之差的绝对值（百分点） | 低 |
| 独立问题覆盖率 | 至少收到有效信息的问题数 ÷ 被遇见的独立问题数 | 高 |
| 工单解决率 | 已解决工单数 ÷ 工单数 | 高 |
| 最后两周参与率 | 第 43—56 日上报数 ÷ 同期普通问题遇见数 | 高 |

有效上报率和重复或无效率在当前定义下互补。成功合并的重复信息被视为有效佐证，不额外生成工单；未合并重复才计入无效负担。

## 4 分析步骤

1. 先运行配置不变量检查。
2. 用固定基础种子运行 4×20 次配对实验。
3. 保存逐事件日志和逐次指标，不筛选“最好的一次”。
4. 计算各情景均值和 95% 置信区间。
5. 用机制递进解释 S0→S1、S1→S2、S2→S3，而不是只比较 S0 与 S3。
6. 记录反直觉结果，例如参与扩大可能带来更多低完整度上报，从而使“有效上报率”与“问题覆盖率”方向不同。

## 5 第二轮敏感性计划

至少改变以下项目，每项使用低、中、高三档并保持其他参数不变：

- 每日问题遇见概率：0.10 / 0.18 / 0.28。
- 基线信任整体平移：-0.15 / 0 / +0.15。
- AI 结构化能力：0.70 / 0.88 / 0.95。
- 反馈概率：0.60 / 0.80 / 0.92。
- 激励强度：0.20 / 0.55 / 0.85。
- 骑手与司机画像差异：无差异 / 当前假设 / 双倍差异。

稳健结论标准：至少 80% 参数组合中方向一致，并且各组合不触发指标越界或安全边界失败。否则最终报告必须写成条件性发现。

## 6 通过条件

- 80 个情景—轮次组合完整。
- 所有比例在 0—1，时间为正数。
- S1→S2、S2→S3 的变化字段符合约定。
- 原始日志能够回溯聚合指标。
- 摘要明确标注合成仿真和局限。
