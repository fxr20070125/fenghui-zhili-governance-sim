# S0—S3 情景配置

## 1 递进关系

| 情景 | 相对上一情景唯一新增机制 | AI 处理 | 透明反馈 | 差异化激励 |
|---|---|---:|---:|---:|
| S0 现状基准 | 基准 | 否 | 否 | 否 |
| S1 AI 上报 | AI 脱敏、结构化、去重、分类和建议分派这一整套上报机制 | 是 | 否 | 否 |
| S2 AI 上报加透明反馈 | 责任主体、进度和结果反馈 | 是 | 是 | 否 |
| S3 AI 上报加透明反馈加差异化激励 | 按服务需求和低参与倾向匹配权益 | 是 | 是 | 是 |

S1 相比 S0 是一个“AI 上报机制包”，所以同时改变耗时、隐私保护、结构化、去重和分派参数；S1→S2 只改变反馈机制；S2→S3 只改变激励机制。`code/validate_config.py` 自动检查后两项递进不变量。

## 2 数值配置摘要

| 参数 | S0 | S1 | S2 | S3 |
|---|---:|---:|---:|---:|
| 平均上报分钟 | 8.0 | 3.0 | 3.0 | 3.0 |
| 隐私保护能力 | 0.10 | 0.85 | 0.85 | 0.85 |
| 结构化能力 | 0.54 | 0.88 | 0.88 | 0.88 |
| 重复合并概率 | 0.15 | 0.75 | 0.75 | 0.75 |
| 建议分派准确参数 | 0.64 | 0.85 | 0.85 | 0.85 |
| 反馈概率 | 0.08 | 0.12 | 0.92 | 0.92 |
| 透明反馈效用 | 0 | 0 | 0.42 | 0.42 |
| 差异化激励强度 | 0 | 0 | 0 | 0.55 |
| 基准处置小时 | 55 | 36 | 30 | 30 |

这些数值全部是第一轮项目假设，不是现实系统测量值。参数来源和第二轮校准计划见 `evidence/parameter-register.md`。

## 3 共同控制项

四个情景共用：人口规模、模拟天数、问题数量与类别、问题严重度、从业者画像、每日遇见概率、基础解决概率、画像分布和指标口径。同一 `run` 的人群与问题由稳定哈希随机数生成，确保机制对比采用共同随机数。
